A chess engine in 4 KB of Python: alpha-beta with iterative deepening, a
transposition table, capture-first move ordering, null-move pruning and a
quiescence search, with no data outside the source file.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:PORT python main.py
```
